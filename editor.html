Conectar con GitHub

Publicar hace un commit en nakarrospide/capo y GitHub Pages lo sube al juego. Para eso hace falta un token del repo, se pega una vez y queda en este navegador.

  1. Abrí github.com/settings/personal-access-tokens/new
  2. En Repository access, elegí Only select repositories y marcá capo.
  3. En Permissions, Contents: Read and write. Generalo y copialo.
